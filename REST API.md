# What is API?

API stands for **A**pplication **P**rogramming **I**nterface. An API is a set of protocols that lets different pieces of software communicate with each other and share data.

There are many **types** of APIs, including REST, SOAP, GraphQL, gRPC, MQTT, etc. Each type of API has a different architectural style and protocol for how requests are made and handled. For example, REST API uses HTTP verbs to create and retrieve resources. gRPC uses HTTP/2 web protocol, which can handle a larger volumes of complex data very well.
